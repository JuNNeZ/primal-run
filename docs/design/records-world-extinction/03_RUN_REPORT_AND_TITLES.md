# System 2 – End-of-run report and run titles

Status: **Partially implemented**. A result screen exists (score, stage, bosses, seconds, a `<details>` block
with raw stats including "Distance (pixels)") and `runSummary()` returns one of six hard-coded titles.
This spec replaces both with a run card built only from the RunSummary (`s`).

## 1. Run card layout (desktop and 390 px mobile)

```
┌──────────────────────────────────────────────┐
│ [portrait]  VELOCIRAPTOR · Bane 5/8 · 12:41    │  header: species, level reached, time
│             ★ PRIMARY TITLE (rarity colour)   │
│             secondary · secondary             │  max 2 secondary titles
├──────────────────────────────────────────────┤
│ Nedlæggelser 34   Bosser 3   Mini-bosser 2    │  row 1: combat
│ Skade 2 140 / 610 (3,5:1)   Største slag 48   │  row 2: damage + efficiency
│ Distance 3,4 km   Områder 14 (78 %)           │  row 3: movement + exploration
│ Føde 41   DNA +36   Mutationer 7 (1 episk)    │  row 4: progress
├──────────────────────────────────────────────┤
│ Dødsårsag: Karl – Askens Jæger (bane 7)       │  or "Sejr – Ragnar faldt"
│ Bosser: Palle 0:41 ✓  Carl 1:12 ✓ (1 forsøg)…  │  boss strip, one chip per boss attempt
│ Nyt: ★ Bedrift "Urørlig"  ✦ Titel "Lavadanser" │  only first-time unlocks
├──────────────────────────────────────────────┤
│ [Se alle tal ▾]   [Del]   [Spil igen]  [Menu] │  details collapsed by default
└──────────────────────────────────────────────┘
```

- Values that are 0 are still shown in the details, but rows on the card hide a cell whose value is 0 and
  is irrelevant to the species (e.g. "Fisk 0" for non-piscivores).
- Ratios are shown only when the denominator is meaningful: efficiency needs damageTaken ≥ 1 (else "∞ –
  ingen skade taget"), accuracy needs attacks ≥ 10.
- Mutation choices: chips in pick order from `mutationLog`, coloured by rarity.
- Special encounters: albino kills, rivals, rare/elite kills, secrets found, lava survived.
- "Del" renders the card to a PNG via the existing canvas pipeline (no network).
- **No fabricated stats.** Every number on the card maps to a variable in `data/run_summary_variables.json`.
  Variables with status `partB:*` are hidden until that package exists.

## 2. Derived statistics (only where the data supports them)

| Derived | Formula | Shown when |
|---|---|---|
| Damage efficiency | damageDealt / damageTaken | damageDealt ≥ 50 |
| Accuracy | landedAttacks / attacks | attacks ≥ 10 |
| Exploration completion | zonesFound / zonesAvailable | always |
| Boss performance | per boss: fight seconds, attempts, hits taken from it | boss met |
| Survival streak | longestNoHitSeconds | ≥ 30 s |
| Pace | distanceM / minutes | minutes ≥ 1 |
| Food per minute | food / minutes | minutes ≥ 1 |

## 3. Titles

The catalogue lives in `data/run_titles.json` (generated by `data/build_titles.py`, readable as
`RUN_TITLES.md`): **95 titles + 1 fallback**. Each has:

- `id`, `name.da`, `name.en`, `description.da/en`
- `condition` – a JavaScript expression over `s` (the RunSummary); the build script rejects undeclared variables
- `priority` 0–100, `rarity` (common → legendary, plus `secret`)
- `tieBreak` – how two runs or two titles of equal rank are ordered (see §4)
- `requiredVariables` and `implementationStatus` (trackable today / needs new tracking / needs Part B)

The other languages (de/sv/no/ja/zh) come from the Danish name through `tools/i18n`; Klingon/Sindarin fall
back to English as today.

Titles are "unlockable": the first time a title is awarded as primary **or secondary** it is added to
`save.titles` with date and count. The collection screen lists earned titles and shows locked ones as
"???" with rarity only (secret titles are hidden entirely until earned).

## 4. Deterministic selection algorithm

```js
const RANK = {common:1, uncommon:2, rare:3, epic:4, legendary:5, secret:6};
function titleScore(t, s) {
  // margin: how far past the threshold, 0..9, used only to separate equal rank+priority
  const m = marginFor(t, s);              // see table below
  return RANK[t.rarity] * 1000 + t.priority * 10 + Math.min(9, m);
}
function pickTitles(s, catalogue, available) {
  const eligible = catalogue.filter(t => available(t) && evalCondition(t, s));   // available(): hides partB titles when the feature is off
  const outcomeOk = t => s.victory ? t.category !== 'shame' || t.id === 'quitter' : true;
  const pool = eligible.filter(outcomeOk);
  pool.sort((a, b) => titleScore(b, s) - titleScore(a, s) || catalogue.indexOf(a) - catalogue.indexOf(b));
  const primary = pool[0] ?? catalogue.find(t => t.id === 'new_branch');
  const secondary = [];
  for (const t of pool.slice(1)) {
    if (secondary.length === 2) break;
    if (t.category === primary.category || secondary.some(x => x.category === t.category)) continue;
    if (t.category === 'fallback') continue;
    secondary.push(t);
  }
  return { primary, secondary };
}
```

Rules:

1. Shame titles are never chosen on a victory (except the quit title, which cannot occur with a victory).
2. On a death, shame titles compete normally; their priorities are set so that a death cause (65–85)
   beats ordinary progress titles but loses to rare/epic achievements of the same run.
3. Secret titles always win (rank 6).
4. `marginFor` by tie-break type:
   - `margin:x` → `floor(3 * (value − threshold) / max(1, threshold))`, threshold parsed from the first
     `s.x >= N` in the condition.
   - `inverse:x` → same, but `(threshold − value)`.
   - `count:…`, `min:a,b` → number of items/min of the named values beyond the threshold.
   - `fixed` → 0.
5. Final tie → catalogue order (the JSON order), which is stable and reviewed.

The same function is used by the bots in `tools/playstyle_sim.cjs` so title distributions can be measured
(target: no non-fallback title is awarded as primary in > 25 % of bot runs; fallback < 10 %).

## 5. Tests

- Unit: every title's condition evaluated against a fixture RunSummary that should and should not satisfy it
  (generated from the threshold in the condition).
- Unit: `pickTitles` returns the same result for the same input 1000× and is independent of object key order.
- Unit: a victory never yields a shame primary.
- Browser: finish a scripted run killed by a compy → card shows "Compy-snack" and the cause line names the compy.
- Snapshot: card fits 390×844 without horizontal scroll in da, de and ja.
