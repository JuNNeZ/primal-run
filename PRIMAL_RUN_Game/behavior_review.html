Adfærd og såret bevægelse

Samme faste native canvas og hoftepunkt som de bevarede sprites. Rolige hovedbevægelser i langsomme par; seks halteframes med to nye skåneben-poses og fire genbrugte gangposes. Alle ark er prototyper og kræver visuel gennemgang.
