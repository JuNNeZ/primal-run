# A2 canonical-body behavior source archive

The original idle144PNG for each direction is the anatomical/colour/hip reference.
Canonical layout PNGs are lossless integer2× preview contact grids, not generated
art; each source animal repeats at fixed192,128 hip in384×256 cells. Generated
revision PNGs are immutable image-generation outputs, with prompts, raw SHA-256,
canonical reference hashes and honest prototype status in matching request JSON.

Main atlas plan:1536×1024,4columns×4rows S/N/E/W. Feed columns0/1graze (predators
sniff),2/3drink. Rest columns0/1sleep,2/3scratch. The final direction-isolated
attempts repeat ONE canonical direction in all16reference cells to prevent body
swelling; only the matching row is eligible for the direction-specific override.
Do not read their unused rows as additional directions.

exports.json declares active source choices, per state/direction overrides,
alpha thresholds, exact hip anchors and rejected paired cycles. Never scale bad
source anatomy to fit: reject bothframes and copy the canonical idle byte-for-
byte as a visibly documented fallback. Runtime eligibility is separate from
production approval. The old player_full/enemy_full resources stay unchanged.

Revision1 scale audit is preserved in body_audit_revision1.json. Subsequent
predator revision ratio reports retain rejected source evidence. Final metrics
are in ../../NATIVE_BEHAVIOR_BODY_AUDIT.json; final technical provenance/palette/
pair-count checks are in ../../NATIVE_BEHAVIOR_VALIDATION.json. Native comparisons
live under ../../previews/behavior_native on light and dark backgrounds.

Every authored pose remains prototype_static, production_approved=false and
animation_ready=false. Quiet motion and fine marking differences remain visual
review items. Technical PNG checks do not approve anatomy, animation or GDevelop.
