# Source generation

Generated with image_gen, transparent_background=true. Original preserved as
jungle_props.png. Requested a1536×1024 strict6×4 sprite atlas in1990s overhead
semi-realistic chunky pixel style, upper-left lighting, muted earthy greens,
no labels/grid/ground/background, one isolated whole object per cell with padding.

Requested rows, left to right:
1. Cycad rosette, broad fern, seed fern, young conifer, horsetail, river reeds.
2. Leafy shrub, purple-fruiting bush, prehistoric herb, dry grass, moss, lichen.
3. Roots, mushrooms, leaf litter, cream flowers, succulent, twigs.
4. Dragonfly raised/spread wings; beetle closed/spread wings; firefly closed/spread wings.

Source has nonuniform row spacing despite the request. Reviewed actual cut
boundaries0/320/575/790/1024 avoid clipped roots/bases. No source pixels painted
or synthesized during extraction. Modern-looking flowering herbs and cattail-like
reeds are stylised placeholders, not botanically identified fossil reconstructions.
Flowering/fruit props are limited to the fantasy Cretaceous river/rock biomes;
forest uses ferns/cycads/conifers. Colours are normalized to the existing32 palette.
