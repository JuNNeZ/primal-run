# Preserved corpse sources

Original ten generated1536x1024 sheets are immutable. sources.json selects
active exports and records source SHA-256 and explicit cell landmarks.
Source plan: S/E/N/W columns; decayed0/decayed1/skeleton0/skeleton1 rows.
Source generation: transparent pixel-art top-down carcass props, canonical
species head/limbs/tail, bone-white/earth palette, no labels, separate variants.

Carnotaurus horn_revision1 fixes E/W single-horn skulls to paired brow horns.
Triceratops horn_revision1 remains a rejected intermediate: north still has a
visible central frill spike. Its next revision hides the nasal horn behind the
frill in the rear north view, exposing only two brow horn tips.
Only corpse/skeleton sources are being repaired; living animation sources stay
unchanged as the user clarified. All sheets remain unapproved prototypes.

Revision2 is the selected Triceratops source. A ten-pixel disconnected neighbouring
tail fragment above north variant1 is explicitly excluded in sources.json during
extraction; source files remain intact. See native light/dark previews and the
static manifest, not this source atlas, for actual in-game pixels.
