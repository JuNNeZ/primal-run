# Foreslåede næste opgraderinger og rettelser

Prioriteret efter hvor meget de forbedrer spiloplevelsen. Dette er forslag,
ikke funktioner der allerede er implementeret.

1. **Finpuds sprites og animationsovergange.** Ensret kropsankre, ben og markeringer
   mellem frames, især når et dyr skifter retning/state. Giv Parasaurolophus og de
   tre store, ældre fjender samme komplette animationsplan som spillerarterne.
2. **Gør terrænet til en del af jagten.** Lav lavt vand med langsommere bevægelse,
   gode vadesteder og buske, som skjuler små dinosaurer. Varsl farligt terræn
   tydeligt, så det er et valg at bruge det i kampen.
3. **Giv dyrene mere liv.** Små flokke, græsning/hvile, territorier og advarsler,
   før territoriale dyr angriber. Predator/bytte-interaktioner kan være sjældne
   naturhændelser med begrænset loot, så spilleren stadig skal jage selv.
4. **Balancér progression med spiltest.** Sammenlign alle fire klassers overlevelse,
   kødhastighed og DNA-indtjening. Justér unlock-priser, efterfølgende bosser og
   mutationskombinationer, så ingen klasse er et oplagt obligatorisk valg.
5. **Mere lyd og stemning.** Biomespecifik vind, vand, insektlyd og fjerne dyrekald;
   flere musikvariationer og rolige overgange til bosskamp. Bevar separate volumes.
6. **Bedre mobil og tilgængelighed.** Flytbar joystick, valgfri automatisk angreb,
   justerbar tekst/HUD, tast-remapping og gamepad. Brug symboler ud over farver
   til at skelne fare og rarity, og tilbyd reduceret bevægelse også inde i spillet.
7. **Kort og opdagelser med større variation.** Ukendte områder på minimappet,
   sjældne små begivenheder, alternative bossarenaer og mulighed for at dele seed.
8. **Kortere indlæsning og mere stabil mobil-performance.** Indlæs kun aktuelle
   biome- og spillerframes; mål hukommelse/fps på telefoner. Brug ruminddeling
   til dyrekollision og tegn kun synlige objekter i store områder.

De første to er min anbefaling: pænere, mere sammenhængende bevægelse og terræn,
som gør jagterne taktisk forskellige, løfter både grafikken og mechanics.
